# Cycle 04 — System → Process → Code

목표: 전체 기술 계층을 먼저 표시하고, 기능별 첫 화면은 파일 그래프가 아닌 처리 단계 요약이다. 세부 단계에서 실제 함수 본문·원본 줄 근거를 펼친다.

## 완료 기준

- Health는 한 응답/한 파일이며 같은 등록 파일의 무관한 추천 기능을 따라가지 않는다.
- 인증·측정·추천은 API/SDK 진입점별 본문을 분리한다. 여러 API를 한 실행 순서처럼 연결하지 않는다.
- 처리 단계의 첫 화면은 최대 8개 연속 묶음. 모든 세부 단계와 근거는 펼칠 수 있다.
- 단계명은 규칙 기반 해석, 선은 소스 읽기 순서, 호출 대상은 정적 후보로 표시한다. 실제 실행/성공은 증명하지 않는다.
- 같은 이름만으로 전역 함수를 연결하지 않는다. 명시적 import와 로컬 정의·클래스만 후보로 해석한다.
- Supabase 직접 인증과 Backend PIN/refresh를 구분한다. 외부 기본 URL을 실제 요청 성공으로 표시하지 않는다.
- 모든 보기와 근거는 같은 Source Snapshot/Graph에서 나온다.
- 회귀 테스트, 실제 소스 의미 검사, HTTP/ZIP/브라우저를 각각 실행하고 원격 결과까지 확인한다.

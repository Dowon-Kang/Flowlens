# FlowLens / 작업 계약

## 목적
낯선 저장소를 처음 본 개발자가 전체 실행 경로를 먼저 이해하고, 선택한 기능의 세부 흐름과 실제 코드 근거로 내려가게 한다. 파일을 전부 나열하는 것이 목적이 아니다.

## 사용자 여정
저장소 URL 또는 로컬 폴더 선택 → System Flow → 기능 선택 → Feature Flow → 노드·화살표의 코드 근거 확인 → 전체로 돌아오기.

## 이번 버전의 범위
- 공개 GitHub 저장소 읽기, 로컬 폴더 읽기, 두 가지 합성 데모.
- JS/TS/Dart의 제한된 정적 패턴 추출, Python의 AST 기반 추출.
- 기술 계층을 묶은 시스템 지도, API 기능별 관련 파일 지도.
- 근거 파일/줄, 확인된 정적 관계와 실행 경로 후보 구분, 분석 범위 공개.
- 선택적인 OpenAI 설명. 키 없이도 정적 분석 가능. 호출은 사용자 동의 시 한 번.
- JSON/SVG/Markdown 내보내기, 개발용 Skills, CI, 회귀 테스트.

## 비목표
완전한 런타임 추적, 모든 언어 지원, 자동 리팩터링, 변경 영향 분석, 운영 배포, 영구 데이터 저장, SaaS 인증/결제, Codex 자동 실행.

## 수용 기준
AC-01 합성 데모가 키·외부 네트워크 없이 동작한다.
AC-02 System Flow는 기술 계층으로 압축하고 함수명·파일명을 기본 화면에서 숨긴다.
AC-03 기능 선택은 같은 canonical graph의 부분집합을 표시한다. 상위 소속을 보존한다.
AC-04 모든 실제 노드·화살표는 존재하는 소스 줄 근거를 갖는다. 사용자 노드 같은 설명용 요소는 명시적으로 virtual이다.
AC-05 HTTP method/path 일치는 후보이며 서버 origin을 검증했다는 표현을 금지한다.
AC-06 누락·지원 제외·용량 제한·실패 파일·잘림을 보여준다. 미확인 연결을 임의로 잇지 않는다.
AC-07 외부 저장소의 명령/AGENTS/스크립트를 실행하지 않는다. 비밀 파일·경로 탈출을 차단한다.
AC-08 AI 출력의 미등록 ID/근거를 거부하고 실패 시 정적 결과를 유지한다.
AC-09 다운로드한 분석 JSON에 commit/snapshot 식별자, 분석기 버전, 단계별 실행 기록을 보존한다.
AC-10 실제 브라우저에서 데모 → 기능 → 근거 → 전체 복귀 → export를 검사한다.

## 완료 판정
Local MVP = 테스트/브라우저 통과. Live GitHub/LLM integration = 별도 실계정·네트워크 검증 필요. 둘을 혼동하지 않는다.
